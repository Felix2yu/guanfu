## M3 完成（commit 7145e25）

- **diarum 契约**（读 diarum 源码确认）：`GET /api/v1/diaries/exists?start&end` → `{dates,entries:[{date,mood,weather,city,temp_min,temp_max,has_content}]}`（一条请求拿区间，含 has_content）；`GET /api/v1/diaries/by-date/:date` → 全文 `{id,date,content(HTML),mood,mood_states,scenarios,weather,city,tags,created,updated,exists}`；`POST /api/v1/auth/login {usernameOrEmail,password}` → `{token}`。
- **diarum 鉴权关键**：REST 中间件只认 `Authorization: Bearer <HS256 JWT>`（`ParseToken` 用 AuthSecret 验签），**MCP 的 32 位 API token 不能用于 REST**；JWT 30 天有效。适配器支持两种 KEY 形态：直传 JWT，或 `用户名:密码` 自动登录换 JWT（解析 exp 提前 1 天重登，401 且为凭证形态时强制重登重试一次）。**形态判定只看是否含冒号**（不再用 isJWT 分支），兼容未来长效 token。
- **immich 契约**（v3.3.1 源码 + 线上 OpenAPI）：`POST /api/search/metadata` body `{takenAfter,takenBefore,page,size,withExif,...}` → `{assets:{items,nextPage},...}`（`nextPage` 为下一页页码，null 结束）；**takenAfter/takenBefore 过滤的是 `asset.fileCreatedAt`（绝对时刻，与时区无关）**，不是 localDateTime——按天窗口翻页必须注意边界。媒体 `GET /api/assets/{id}/thumbnail|original`（`x-api-key` 头）。
- **photo 事件按天聚合**：一天一张卡，`summary` = 相机型号 · 时段 · 收藏数；detail 含 cameras/cities/count/favorites；media 挂 thumbnail+original 双引用。
- **媒体代理**：`GET /api/v1/media/immich/{uuid}?size=thumbnail|preview|original`；UUID 正则校验 + size 白名单（非法 400）+ 回源带 `x-api-key`；原图 CopyN 上限放宽 256MB，其余 32MB。
